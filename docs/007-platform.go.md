# 007-platform.go

## 文件概述
`platform.go` 是 beancount-gs 项目中负责处理平台特定功能的工具文件。该文件提供了检测操作系统类型和在不同操作系统上打开浏览器的功能，确保项目在不同平台上的兼容性和用户体验。

## 主要功能
1. **操作系统检测**：检测当前运行的操作系统类型（Windows、macOS）
2. **浏览器打开**：根据不同操作系统使用适当的命令打开浏览器

## 关键组件

### 操作系统检测函数
- `isWindows() bool`：判断当前操作系统是否为 Windows
- `isMacOS() bool`：判断当前操作系统是否为 macOS

### 浏览器操作函数
- `OpenBrowser(url string)`：根据当前操作系统打开浏览器并访问指定 URL

## 技术特点
- 使用 Go 标准库的 `runtime` 包检测操作系统类型
- 使用 `os/exec` 包执行系统命令
- 根据不同操作系统选择适当的命令打开浏览器
- 实现了错误处理和日志记录
- 支持 Windows 和 macOS 两种主要操作系统

## 应用场景
- 在用户界面中打开浏览器展示报表或图表
- 打开在线帮助文档
- 打开认证页面
- 在本地开发环境中测试 Web 界面

## 实现细节
- Windows 系统使用 `cmd /C start url` 命令打开浏览器
- macOS 系统使用 `open url` 命令打开浏览器
- 命令执行错误会被记录到系统日志中

## 注意事项
- 当前实现仅支持 Windows 和 macOS，不支持 Linux 系统
- 命令执行是异步的，使用 `cmd.Start()` 而非 `cmd.Run()`
- 错误处理仅记录日志，不会中断程序执行
- 在某些环境下（如无图形界面的服务器），打开浏览器功能可能无法正常工作
