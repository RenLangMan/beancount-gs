# 002-bql.go

## 文件概述
`bql.go` 是 beancount-gs 项目中负责处理 Beancount Query Language (BQL) 查询的核心文件。该文件实现了构建、执行和解析 BQL 查询的功能，是项目与 Beancount 数据交互的关键组件。

## 主要功能
1. **BQL 查询构建**：根据查询参数动态构建 BQL 查询语句
2. **查询执行**：调用 bean-query 命令执行 BQL 查询
3. **结果解析**：将查询结果解析为结构化数据
4. **错误处理**：提供调试模式下的详细错误信息

## 关键组件

### 结构体
- `QueryParams`：定义查询参数，包含多个字段用于构建查询条件，如 From、Where、ID、Year、Month、Account 等

### 主要函数
- `GetQueryParams()`：从 gin.Context 中解析查询参数
- `BQLQueryList()`：执行 BQL 查询并将结果解析到指定的结构体中
- `BQLQueryListByCustomSelect()`：使用自定义 SELECT 语句执行 BQL 查询
- `BQLPrint()`：打印指定 ID 的交易记录
- `bqlRawQuery()`：构建并执行原始 BQL 查询
- `queryByBQL()`：调用 bean-query 命令执行 BQL 查询
- `parseResult()`：解析查询结果，支持多种格式
- `parseCustomFormat()`：解析自定义分隔符格式
- `parseTableFormat()`：解析表格格式
- `BeanReportAllPrices()`：查询所有价格信息

### 辅助函数
- `handleError()`：根据调试模式处理错误
- `escapeSQLString()`：安全转义 SQL 字符串
- `assertQueryResultIsPointer()`：确保查询结果是指针类型
- `marshalAndUnmarshal()`：通用的 JSON 序列化和反序列化

## 技术特点
- 支持多种查询格式和结果解析方式
- 使用反射机制动态构建查询和解析结果
- 提供详细的调试日志
- 支持虚拟环境执行 bean-query 命令
- 实现了降级方案，确保即使虚拟环境有问题也能工作

## 注意事项
- 查询参数需要经过有效性检查
- 查询结果必须是指针类型
- 支持调试模式下的详细日志输出
- 提供了多种格式的结果解析方式，包括自定义分隔符格式和表格格式
