# 008-sort.go

## 文件概述
`sort.go` 是 beancount-gs 项目中负责排序功能的工具文件。该文件实现了两种自定义排序类型，用于对账户类型和账户进行排序，确保项目中的数据能够按照特定规则有序展示。

## 主要功能
1. **账户类型排序**：实现 `AccountType` 类型的排序功能
2. **账户排序**：实现 `Account` 类型的排序功能

## 关键组件

### 账户类型排序
- `AccountTypeSort`：基于 `AccountType` 类型的排序结构体
  - `Len() int`：获取元素数量
  - `Swap(i, j int)`：交换两个元素的位置
  - `Less(i, j int) bool`：比较两个元素的大小（基于 `Key` 字段）

### 账户排序
- `AccountSort`：基于 `Account` 类型的排序结构体
  - `Len() int`：获取元素数量
  - `Swap(i, j int)`：交换两个元素的位置
  - `Less(i, j int) bool`：比较两个元素的大小（基于 `Acc` 字段）

## 技术特点
- 实现了 Go 标准库 `sort.Interface` 接口的三个必要方法
- 使用字符串比较进行排序
- 排序规则简单高效
- 支持标准库的 `sort.Sort()` 函数调用

## 应用场景
- 对账户类型列表进行排序
- 对账户列表进行排序
- 在报表和界面中展示有序数据

## 注意事项
- 排序基于字符串比较，区分大小写
- 排序是原地进行的，会修改原始数据
- 需要确保被排序的字段不为空
- 排序性能为 O(n log n)
