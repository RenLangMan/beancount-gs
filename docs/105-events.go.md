# 105-events.go

## 文件概述
`events.go` 是 beancount-gs 项目中负责事件管理的服务文件。该文件实现了事件的查询、添加和删除功能，是项目中事件管理的核心组件。

## 主要功能
1. **事件查询**：获取所有事件并按时间排序
2. **事件添加**：添加新事件
3. **事件删除**：删除指定事件

## 关键组件

### 事件结构体
- `Event`：事件结构体
  - `Date`：事件日期
  - `Stage`：事件阶段
  - `Type`：事件类型
  - `Types`：事件类型数组
  - `Description`：事件描述

### 事件切片
- `Events`：事件切片类型，实现了 `sort.Interface` 接口
  - `Len()`：获取事件数量
  - `Less()`：比较两个事件的日期
  - `Swap()`：交换两个事件的位置

### 主要函数
- `GetAllEvents(c *gin.Context)`：获取所有事件并按时间倒序排列
- `AddEvent(c *gin.Context)`：添加新事件
- `DeleteEvent(c *gin.Context)`：删除指定事件

## 技术特点
- 使用 Gin 框架处理 HTTP 请求
- 实现了自定义排序接口
- 支持批量添加事件类型
- 提供了完整的错误处理和响应机制
- 使用文件操作持久化事件数据

## 应用场景
- 展示事件时间线
- 添加重要事件记录
- 删除错误或过时的事件
- 管理账本中的关键事件

## 注意事项
- 事件日期需要符合特定格式
- 事件类型和描述需要正确转义
- 文件操作可能会失败，需要正确处理错误
- 排序是按日期倒序排列
