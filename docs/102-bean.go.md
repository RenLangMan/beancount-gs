# 102-bean.go

## 文件概述
`bean.go` 是 beancount-gs 项目中负责账本文件管理的服务文件。该文件提供了按月创建账本文件的功能，确保账本数据能够按月份组织和管理。

## 主要功能
1. **按月创建账本文件**：为指定月份创建账本文件
2. **自动包含到月份总文件**：将新创建的月份文件自动包含到 months.bean 文件中

## 关键函数
- `CreateMonthBeanFileIfNotExist(ledgerDataPath string, month string) error`：
  - 功能：如果指定月份的账本文件不存在，则创建该文件
  - 参数：
    - `ledgerDataPath`：账本数据目录路径
    - `month`：月份字符串，格式为 "YYYY-MM"
  - 返回值：成功返回 nil，失败返回错误信息

## 技术特点
- 使用 `script` 包的文件操作函数
- 实现了文件存在性检查
- 自动维护 months.bean 文件的包含关系
- 提供了错误处理和日志记录

## 应用场景
- 按月组织账本数据
- 自动创建新的月份账本文件
- 确保账本文件结构的完整性

## 注意事项
- 月份参数需要符合 "YYYY-MM" 格式
- 账本数据目录需要正确配置
- 文件创建和写入操作可能会失败，需要正确处理错误
