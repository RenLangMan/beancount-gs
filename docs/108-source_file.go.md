# 108-source_file.go

## 文件概述
`source_file.go` 是 beancount-gs 项目中负责账本源文件管理的服务文件。该文件实现了账本源文件的查询、内容获取和更新功能，是项目中文件管理的核心组件。

## 主要功能
1. **源文件目录查询**：查询账本源文件目录结构
2. **源文件内容查询**：获取指定源文件的内容
3. **源文件内容更新**：更新指定源文件的内容
4. **自动备份**：更新文件前自动备份原文件

## 关键组件

### 查询函数
- `QueryLedgerSourceFileDir(c *gin.Context)`：查询账本源文件目录结构
  - 使用 `dirs()` 辅助函数递归遍历目录
- `QueryLedgerSourceFileContent(c *gin.Context)`：获取指定源文件的内容

### 更新函数
- `UpdateLedgerSourceFileContent(c *gin.Context)`：更新指定源文件的内容
  - 支持自动备份
  - 更新货币文件后自动刷新缓存

### 辅助函数
- `dirs(parent string, dirPath string) ([]string, error)`：递归遍历目录结构

### 数据结构
- `UpdateSourceFileForm`：更新源文件表单
  - `Path`：文件路径（相对账本目录）
  - `Content`：文件内容

## 技术特点
- 使用 Gin 框架处理 HTTP 请求
- 递归遍历目录结构
- 支持文件自动备份
- 更新货币文件后自动刷新缓存
- 提供了完整的错误处理和响应机制
- 使用文件操作管理账本数据

## 应用场景
- 展示账本源文件目录结构
- 查看账本源文件内容
- 编辑账本源文件
- 自动备份重要文件
- 更新货币配置后自动刷新缓存

## 注意事项
- 文件路径需要正确指定
- 备份功能需要配置开启
- 递归遍历可能性能较低
- 文件操作可能会失败，需要正确处理错误
