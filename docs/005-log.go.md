# 005-log.go

## 文件概述
`log.go` 是 beancount-gs 项目中负责日志记录的工具文件。该文件实现了一个分级日志系统，支持不同级别（Info、Warn、Error、Debug）的日志记录，并提供了针对系统级别和账本级别的日志记录函数，是项目中日志管理的核心组件。

## 主要功能
1. **分级日志记录**：支持 Info、Warn、Error、Debug 四个级别的日志
2. **上下文日志**：支持记录带有上下文信息的日志
3. **系统日志**：专门用于记录系统级别的日志
4. **调试日志**：仅在调试模式下输出的日志
5. **BQL查询日志**：专门用于记录 BQL 查询相关的日志

## 关键组件

### Info 级别日志函数
- `LogInfo(ledgerName string, message string)`：记录信息级别的日志
- `LogSystemInfo(message string)`：记录系统信息日志

### Warn 级别日志函数
- `LogWarn(ledgerName string, context string, format string, args ...interface{})`：记录警告级别的日志
- `LogSystemWarn(context string, format string, args ...interface{})`：记录系统级警告日志

### Error 级别日志函数
- `LogError(ledgerName string, message string)`：记录错误日志
- `LogErrorDetailed(ledgerName string, context string, format string, args ...interface{})`：记录带有详细信息的错误日志
- `LogSystemError(message string)`：记录系统级错误信息
- `LogSystemErrorDetailed(context string, format string, args ...interface{})`：记录系统级错误日志，包含详细上下文信息

### Debug 级别日志函数
- `LogDebug(ledgerName string, message string)`：在调试模式下记录调试日志
- `LogDebugDetailed(ledgerName string, context string, format string, args ...interface{})`：在调试模式下记录详细的调试日志
- `LogSystemDebug(message string)`：记录系统级别的调试日志
- `LogSystemDebugDetailed(context string, format string, args ...interface{})`：记录系统级调试日志，包含详细上下文信息

### 特殊功能日志函数
- `LogBQLQueryDebug(ledgerName string, context string, format string, args ...interface{})`：在调试模式下记录BQL查询日志

## 技术特点
- 使用 Go 标准库的 `fmt` 和 `time` 包实现日志功能
- 日志格式统一，包含时间戳、日志级别、账本名称和消息内容
- 支持格式化字符串，方便构建复杂的日志消息
- 调试日志受 `IsDebugMode()` 函数控制，只在调试模式下输出
- 支持带上下文的日志记录，便于定位问题
- 系统级日志函数是对基础日志函数的封装，简化系统日志的记录

## 应用场景
- 记录系统启动和配置加载信息
- 记录账本操作和交易处理过程
- 记录错误和异常情况
- 在调试模式下记录详细的执行流程
- 记录 BQL 查询的执行情况
- 记录文件操作的成功和失败

## 日志格式
- **Info 级别**：`[Info] [时间] [账本名称]: 消息`
- **Warn 级别**：`[Warn] [时间] [账本名称][上下文]: 消息`
- **Error 级别**：`[Error] [时间] [账本名称]: 消息` 或 `[Error] [时间] [账本名称][上下文]: 消息`
- **Debug 级别**：`[Debug] [时间] [账本名称]: 消息` 或 `[Debug] [时间] [账本名称][上下文]: 消息`

## 注意事项
- Debug 级别的日志只在调试模式下输出，需要通过 `IsDebugMode()` 函数控制
- 系统级日志使用 "System" 作为账本名称
- 带有详细信息的日志函数支持格式化字符串和可变参数
- 日志时间戳使用 "2006-01-02 15:04:05" 格式
