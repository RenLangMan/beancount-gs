# 005 - Beancount 菜单脚本说明

## 功能概述

`menu.sh` 是一个 Bash 脚本，提供了 Beancount v3 系统的交互式菜单界面，简化了常用操作流程。

## 主要功能

1. 构建并运行 beancount-gs 服务
2. 管理 Python 虚拟环境
3. 规则生成器的完整和分步操作
4. 环境状态检查

## 菜单选项说明

### 1. 构建并运行 beancount-gs

- 自动检测并激活虚拟环境
- 编译 Go 项目生成 beancount-gs 可执行文件
- 后台运行服务并记录 PID

### 2. 激活虚拟环境

- 激活 Beancount v3 的 Python 虚拟环境
- 显示当前 Python 版本和路径

### 3. 运行规则生成器 (完整流程)

- 执行规则生成器的完整流程：
  - 初始化数据库
  - 加载并提取数据
  - 分析规则
  - 生成规则文件

### 4. 分步运行规则生成器

提供灵活的步骤组合：

1. 初始化数据库
2. 加载并提取数据
3. 分析规则
4. 生成规则文件
5. 步骤1+2 (初始化+加载)
6. 步骤1+2+3 (初始化+加载+分析)
7. 步骤2+3 (加载+分析)
8. 步骤2+3+4 (加载+分析+生成)
9. 完整流程(步骤1+2+3+4)

### 5. 仅激活虚拟环境并进入Python

- 激活虚拟环境后进入 Python 交互模式

### 6. 检查环境状态

- 检查虚拟环境状态
- 检查 beancount-gs 运行状态
- 检查规则生成器脚本是否存在

## 使用示例

```bash
# 给脚本添加执行权限
chmod +x menu.sh

# 运行菜单
./menu.sh
```

## 注意事项

1. 确保已安装所有依赖项：
   - Python 虚拟环境
   - Go 编译环境
2. 默认账本ID为：`3978d009748ef54ad6ef7bf851bd55491b1fe6bb`
3. 脚本需要在项目根目录(/workspace)下运行
4. 使用 Ctrl+C 可中断正在运行的操作
