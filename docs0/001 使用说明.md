# Beancount-GS 使用说明

## 项目概述

Beancount-GS 是一个基于 Beancount v3 的个人财务管理系统，结合了 Go 语言后端和 Fava 前端界面，提供了便捷的记账和财务分析功能。

## 系统要求

- Go 1.17+
- Python 3.x
- Docker (可选，用于容器化部署)

## 安装指南

### 方法一：直接安装

1. 克隆仓库到本地
2. 创建 Python 虚拟环境并安装依赖：

```bash
python -m venv .env_beancount-v3
. .env_beancount-v3/bin/activate  # Linux/macOS
# 或在 Windows 上使用：
# .env_beancount-v3\Scripts\activate

pip install --upgrade pip
pip install beancount==3.1.0 fava==1.30.5 beanquery==0.2.0 beangulp==0.2.0 dateparser==1.2.2
```

3. 构建 Go 程序：

```bash
go build .
```

4. 启动服务：

```bash
./beancount-gs
```

### 方法二：使用 Docker

使用提供的 Docker 配置文件进行构建和运行：

```bash
docker-compose up -d
```

## 开发环境设置

### 使用云端开发环境（CNB）

项目支持通过 CNB 云端开发环境进行开发，配置文件为 `.cnb.yml`。系统使用自定义Dockerfile（Dockerfile-python-go）创建同时包含Go和Python环境的容器。根据不同分支，系统会自动配置相应的开发环境：

- **main 分支**：在同一环境中构建Go程序并运行Python应用，安装基本依赖
- **dev 分支**：在同一环境中构建Go程序并运行Python应用，额外安装开发和测试工具

这种集成的环境配置简化了开发流程，消除了在不同环境间切换的需要。

### 本地开发

1. 克隆 dev 分支
2. 运行 `start_dev.sh` 脚本设置开发环境：

```bash
./start_dev.sh
```

## 项目结构

- `/config` - 配置文件
- `/data` - 数据存储目录
- `/lib` - 依赖库
- `/logs` - 日志文件
- `/public` - 前端静态资源
- `/script` - Go 脚本文件
- `/service` - 核心服务实现
- `/template` - Beancount 模板文件
- `/tests` - 测试文件

## 使用方法

1. 启动服务后，通过浏览器访问 Fava 界面（默认为 http://localhost:5000）
2. 使用模板创建账户和交易记录
3. 利用 Fava 提供的报表和分析功能查看财务状况
4. 使用 beanquery 进行高级查询：
   ```bash
   # 在命令行中使用beanquery
   beanquery run "SELECT * FROM transactions" /path/to/your/beancount/file.bean
   ```
   或在 Fava 界面中使用 SQL 查询功能

## beanquery 查询指南

beanquery 是 Beancount 的查询语言工具，允许您使用类似 SQL 的语法查询财务数据。

### 基本查询示例

```sql
-- 查询所有交易
SELECT * FROM transactions;

-- 查询特定账户的交易
SELECT * FROM transactions WHERE account ~ 'Expenses:Food';

-- 查询特定日期范围的交易
SELECT * FROM transactions WHERE date >= 2023-01-01 AND date <= 2023-12-31;

-- 按月汇总支出
SELECT year(date) as year, month(date) as month, sum(cost(position)) as expenses
FROM postings
WHERE account ~ 'Expenses:' 
GROUP BY year, month
ORDER BY year, month;
```

### 高级查询功能

- 支持聚合函数：`sum()`, `avg()`, `min()`, `max()`, `count()`
- 支持日期函数：`year()`, `month()`, `day()`
- 支持正则表达式匹配：使用 `~` 操作符
- 支持复杂的 JOIN 操作
- 支持子查询和临时表

## 最近变更

### 2023年变更

- 将 `.cnb.yml` 文件中的 `source` 命令替换为 `.` 命令，提高了在标准 POSIX shell 环境中的兼容性
- 在 main 分支和 dev 分支配置中都进行了相应修改
- 保留了 `start_dev.sh` 脚本中的 `source` 命令，因为它是专为 Git Bash 环境设计的

## 常见问题

### 启动失败

如果遇到启动失败的情况，请检查：

1. Python 虚拟环境是否正确激活
2. 所有依赖是否已安装
3. Go 程序是否已成功构建

### 数据导入问题

如果遇到数据导入问题，请确保：

1. 导入文件格式正确
2. 账户已在系统中定义
3. 交易记录符合 Beancount 语法规范
