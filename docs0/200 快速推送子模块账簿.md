## 创建推送脚本

```bash
# 创建脚本目录（如果不存在）
mkdir -p /workspace/.scripts/

# 创建推送脚本
cat > /workspace/.scripts/git_push.sh << 'EOF'
#!/bin/bash

# 脚本配置
SCRIPT_DIR="$(dirname "$(realpath "$0")")"
PUSH_COUNT_FILE="$SCRIPT_DIR/.push_count"
REPO_DIR="/workspace/data/beancount/3978d009748ef54ad6ef7bf851bd55491b1fe6bb"

# 切换到仓库目录
cd "$REPO_DIR" || { echo "无法进入仓库目录: $REPO_DIR"; exit 1; }

# 获取当前分支
BRANCH=$(git branch --show-current)

# 读取或初始化推送次数
if [ -f "$PUSH_COUNT_FILE" ]; then
    PUSH_COUNT=$(cat "$PUSH_COUNT_FILE")
else
    PUSH_COUNT=0
fi

# 增加推送次数
PUSH_COUNT=$((PUSH_COUNT + 1))
echo "$PUSH_COUNT" > "$PUSH_COUNT_FILE"

# 生成提交信息
TIMESTAMP=$(date +"%Y-%m-%d %H:%M:%S")
COMMIT_MSG="push#$PUSH_COUNT - $TIMESTAMP"

# 如果有参数，使用参数作为提交信息
if [ $# -gt 0 ]; then
    COMMIT_MSG="$*"
fi

# 执行 Git 操作
echo "正在添加文件..."
git add .

echo "正在提交: $COMMIT_MSG"
git commit -m "$COMMIT_MSG"

echo "正在推送到远程仓库..."
git push

echo "✅ 推送完成! (第 $PUSH_COUNT 次推送)"
echo "分支: $BRANCH"
echo "时间: $TIMESTAMP"
EOF

# 给脚本执行权限
chmod +x /workspace/.scripts/git_push.sh
```

## 设置别名

将以下别名添加到您的 `~/.bashrc` 文件中：

```bash
# 添加到 ~/.bashrc
echo 'alias gp="/workspace/.scripts/git_push.sh"' >> ~/.bashrc
echo 'alias gpc="/workspace/.scripts/git_push.sh 自定义提交信息"' >> ~/.bashrc

# 立即生效
source ~/.bashrc
```

## 使用方法

### 1. 使用自动生成的提交信息（包含次数和时间）
```bash
gp
```
这会生成如：`push#1 - 2024-01-15 14:30:25` 的提交信息

### 2. 使用自定义提交信息
```bash
gp "修复了记账错误"
# 或
gpc "添加了新的交易记录"
```

### 3. 带参数的自定义信息
```bash
gp 更新月度报表
```

## 其他有用的 Git 别名

您还可以添加这些常用别名到 `~/.bashrc`：

```bash
echo 'alias gs="git status"' >> ~/.bashrc
echo 'alias ga="git add ."' >> ~/.bashrc  
echo 'alias gc="git commit -m"' >> ~/.bashrc
echo 'alias gl="git log --oneline --graph -10"' >> ~/.bashrc
source ~/.bashrc
```

1. **自动计数**: 每次推送自动记录次数
2. **时间戳**: 包含精确的提交时间
3. **自定义消息**: 支持自定义提交信息
4. **错误处理**: 基本的错误检查
5. **状态反馈**: 显示操作进度和结果
