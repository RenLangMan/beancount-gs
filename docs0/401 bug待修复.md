从日志中可以看到两个主要的错误需要修复：

## 错误分析

### 1. Beanquery 库的语法错误
```python
SyntaxError: cannot use starred expression here (<string>, line 4)
return hash((*self[0]))
```

### 2. 查询语法错误
```sql
SELECT DISTINCT payee WHERE limit 100 ORDER BY date desc LIMIT 100
```

## 修复方案

### 1. 修复 Beanquery 库的兼容性问题

首先检查并更新 beanquery 库：

```bash
# 检查当前安装的 beanquery 版本
pip show beanquery

# 更新 beanquery 到最新版本
pip install --upgrade beanquery

# 或者安装特定兼容版本
pip install beanquery==0.2.0
```

### 2. 修复查询语法错误

找到生成错误查询的代码并修正。根据日志，问题出现在：

1. **标签查询**：`SELECT DISTINCT tags`
2. **收款人查询**：`SELECT DISTINCT payee WHERE limit 100 ORDER BY date desc LIMIT 100`

**修正后的查询应该是**：

对于标签查询：
```sql
SELECT DISTINCT tags WHERE tags IS NOT NULL
```

对于收款人查询：
```sql
SELECT DISTINCT payee ORDER BY date desc LIMIT 100
```

或者如果确实需要条件：
```sql
SELECT DISTINCT payee WHERE [条件表达式] ORDER BY date desc LIMIT 100
```

### 3. 手动修复 beanquery 库文件

如果更新库不能解决问题，可以手动修复 `hashable.py` 文件：

```bash
# 找到 hashable.py 文件位置
find /workspace/.env_beancount-v3 -name "hashable.py"

# 编辑该文件
nano /workspace/.env_beancount-v3/lib/python3.12/site-packages/beanquery/hashable.py
```

找到第75行附近的代码：
```python
exec(code, globals(), ns)
```

以及相关的代码生成部分，将：
```python
return hash((*self[0]))
```

修改为：
```python
return hash(tuple(self[0]))
```

### 4. 检查应用程序代码

找到生成这些查询的应用程序代码并进行修正。根据错误信息，这些查询可能来自：

1. `QueryTags` 函数 - 生成 `SELECT DISTINCT tags`
2. `QueryTransactionPayees` 函数 - 生成 `SELECT DISTINCT payee WHERE limit 100 ORDER BY date desc LIMIT 100`

**修正建议**：

对于标签查询函数：
```go
// 原来的错误代码
query := "SELECT DISTINCT tags"

// 修正为
query := "SELECT DISTINCT tags WHERE tags IS NOT NULL"
```

对于收款人查询函数：
```go
// 原来的错误代码  
query := "SELECT DISTINCT payee WHERE limit 100 ORDER BY date desc LIMIT 100"

// 修正为
query := "SELECT DISTINCT payee ORDER BY date desc LIMIT 100"
```

### 5. 安装缺失的依赖

日志中还显示缺少 `pyzipper` 模块：
```bash
pip install pyzipper
```

## 执行修复步骤

```bash
# 1. 安装缺失的依赖
pip install pyzipper

# 2. 更新 beanquery
pip install --upgrade beanquery

# 3. 如果更新后仍有问题，手动修复 hashable.py
# 先备份
cp /workspace/.env_beancount-v3/lib/python3.12/site-packages/beanquery/hashable.py /workspace/.env_beancount-v3/lib/python3.12/site-packages/beanquery/hashable.py.bak

# 使用 sed 进行修复
sed -i 's/return hash((\*self\[0\]))/return hash(tuple(self[0]))/g' /workspace/.env_beancount-v3/lib/python3.12/site-packages/beanquery/hashable.py

# 4. 重新启动服务
pkill beancount-gs
/workspace/start_on_cnb.sh
```

完成这些修复后，Beanquery 的语法错误应该能够得到解决。如果问题仍然存在，可能需要检查应用程序中生成查询的具体代码逻辑。
