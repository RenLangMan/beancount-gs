# Beancount-GS 技术文档

## 技术架构

Beancount-GS 采用了前后端分离的架构设计：

### 后端架构

- **Go 语言服务**：提供核心业务逻辑和API接口
  - 文件管理
  - 账户管理
  - 交易处理
  - 数据统计分析
  - 事件处理

- **Beancount 引擎**：基于 Python 的开源复式记账系统
  - 提供复式记账核心功能
  - 处理账户、交易、余额等财务数据
  - 支持查询语言 (BQL)
  - 集成 beanquery 高级查询功能

### 前端架构

- **Fava**：Beancount 的 Web 界面
  - 提供直观的数据可视化
  - 支持交易编辑和查询
  - 提供报表和图表功能

## 核心模块说明

### 服务模块 (`/service`)

- **accounts.go**: 账户管理相关功能
- **bean.go**: Beancount 核心功能封装
- **commodity.go**: 货币和商品管理
- **events.go**: 事件处理
- **import.go**: 数据导入功能
- **ledger.go**: 账本管理
- **transactions.go**: 交易处理
- **stats.go**: 统计分析

### 脚本模块 (`/script`)

- **bql.go**: Beancount 查询语言处理
- **config.go**: 配置管理
- **file.go**: 文件操作
- **log.go**: 日志处理
- **paths.go**: 路径管理
- **platform.go**: 平台兼容性处理
- **sort.go**: 排序算法
- **utils.go**: 通用工具函数

## 数据流程

1. 用户通过 Fava 界面或 API 提交财务数据
2. Go 服务接收请求并处理数据
3. 数据转换为 Beancount 格式并存储
4. Beancount 引擎处理数据并生成结果
5. 结果通过 API 返回或在 Fava 界面展示
6. 用户可通过 beanquery 执行高级查询分析

## beanquery 技术实现

### 概述

beanquery 是 Beancount 的查询组件，提供类似 SQL 的查询语言，用于分析 Beancount 财务数据。本项目已完整集成 beanquery 功能，支持通过命令行和 Fava 界面进行查询操作。

### 实现细节

1. **查询引擎**：
   - 基于 Python 实现的 SQL 解析器和执行引擎
   - 支持标准 SQL 语法的子集，并添加了财务数据特定的扩展
   - 使用 PLY (Python Lex-Yacc) 进行语法解析

2. **数据模型**：
   - 将 Beancount 的账本数据映射为关系型数据模型
   - 主要表包括：`entries`, `postings`, `transactions`, `accounts`, `commodities` 等
   - 支持视图和虚拟表，便于常见查询场景

3. **查询优化**：
   - 实现了基本的查询计划优化
   - 支持索引加速常见查询模式
   - 针对大型账本数据进行了性能优化

4. **集成方式**：
   - 命令行接口：通过 `beanquery` 命令直接查询 Beancount 文件
   - Fava 集成：在 Fava 界面中提供 SQL 查询表单
   - API 接口：提供编程方式访问查询功能

5. **扩展功能**：
   - 自定义函数支持：允许用户定义和使用自定义函数
   - 结果格式化：支持多种输出格式，包括表格、CSV、JSON 等
   - 查询历史：保存和重用常用查询

## 开发指南

### 环境设置

#### 必要工具

- Go 1.17+
- Python 3.x
- Git

#### 开发环境配置

1. 克隆仓库：
   ```bash
   git clone <repository-url>
   git checkout dev
   ```

2. 设置 Python 虚拟环境：
   ```bash
   python -m venv .env_beancount-v3
   . .env_beancount-v3/bin/activate  # Linux/macOS
   # 或在 Windows 上：
   # .env_beancount-v3\Scripts\activate
   ```

3. 安装依赖：
   ```bash
   pip install --upgrade pip
   pip install -r requirements-beancount-v3.txt
   ```

4. 构建 Go 程序：
   ```bash
   go build .
   ```

### 代码规范

#### Go 代码规范

- 遵循 [Go 官方代码规范](https://golang.org/doc/effective_go)
- 使用 `gofmt` 格式化代码
- 添加适当的注释和文档
- 编写单元测试

#### Python 代码规范

- 遵循 [PEP 8](https://www.python.org/dev/peps/pep-0008/) 规范
- 使用类型注解
- 添加文档字符串

### 测试指南

#### 运行测试

```bash
go test ./tests
```

#### 添加新测试

在 `/tests` 目录下添加新的测试文件，遵循 Go 测试命名规范。

### API 文档

#### 核心 API

| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/accounts` | GET | 获取所有账户 |
| `/api/transactions` | GET | 获取交易列表 |

| `/api/stats` | GET | 获取统计数据 |

## 部署指南

### 直接部署

1. 构建 Go 程序：
   ```bash
   go build -o beancount-gs .
   ```

2. 配置环境变量（可选）：
   ```bash
   export BEANCOUNT_DATA_DIR=/path/to/data
   ```

3. 运行程序：
   ```bash
   ./beancount-gs
   ```

### Docker 部署

1. 构建 Docker 镜像：
   ```bash
   docker build -t beancount-gs .
   ```

2. 运行容器：
   ```bash
   docker run -d -p 5000:5000 -v /path/to/data:/app/data beancount-gs
   ```

### 云端部署 (CNB)

项目支持通过 CNB 云端环境进行部署，配置文件为 `.cnb.yml`。

#### 环境配置

项目使用 `.cnb.yml` 文件配置云端开发环境，支持多分支配置：

- **通用配置**：使用自定义Dockerfile（Dockerfile-python-go）创建同时包含Go和Python环境的容器
- **main 分支**：在同一环境中构建Go程序并运行Python应用，安装基本依赖
- **dev 分支**：在同一环境中构建Go程序并运行Python应用，额外安装开发和测试工具

这种集成的环境配置简化了开发流程，消除了在不同环境间切换的需要，同时保持了开发和生产环境的功能区分。

## 故障排除

### 常见错误

1. **Python 依赖问题**
   - 症状：启动失败，Python 模块导入错误
   - 解决方案：检查虚拟环境是否激活，重新安装依赖

2. **Go 构建错误**
   - 症状：构建失败，编译错误
   - 解决方案：检查 Go 版本，更新依赖

3. **数据文件访问错误**
   - 症状：运行时错误，无法读写数据文件
   - 解决方案：检查文件权限，确保数据目录存在

## 性能优化

1. **查询优化**
   - 使用索引提高查询速度
   - 缓存常用查询结果

2. **内存管理**
   - 避免大量数据一次性加载
   - 使用流式处理大型数据集

3. **并发处理**
   - 利用 Go 的 goroutine 进行并发操作
   - 使用适当的锁机制避免竞态条件
