# 同步脚本使用说明

本文档介绍了 `.scripts/sync_to_github_gitee.sh` 脚本的使用方法。该脚本用于将本地代码同步到 GitHub 和 Gitee 远程仓库。

## 功能特点

### 1. 灵活的仓库选择

- 支持传递1-2个仓库URL参数
- 可以只推送到GitHub
- 可以只推送到Gitee
- 可以同时推送到GitHub和Gitee
- 自动根据URL识别仓库类型（GitHub或Gitee）

### 2. 交互式分支选择

- 不再需要通过命令行参数指定分支
- 脚本会列出所有可用的本地分支
- 用户可以交互式选择要推送的本地分支
- 支持默认远程分支名前缀（`feat-beanquery-cnb/`）
- 可以选择使用默认的远程分支名（本地分支名加上前缀）
- 也可以手动指定不同的远程分支名

### 3. 智能推送

- 只在需要推送到相应平台时执行相关操作
- 自动处理远程仓库的添加和更新
- 在URL不匹配时询问是否要更新

## 使用方法

基本语法：

```bash
./.scripts/sync_to_github_gitee.sh [仓库URL1] [仓库URL2]
```

### 使用示例

#### 1. 只推送到GitHub

```bash
./.scripts/sync_to_github_gitee.sh https://github.com/username/repo.git
```

#### 2. 只推送到Gitee

```bash
./.scripts/sync_to_github_gitee.sh https://gitee.com/username/repo.git
```

#### 3. 同时推送到GitHub和Gitee

```bash
./.scripts/sync_to_github_gitee.sh https://github.com/username/repo.git https://gitee.com/username/repo.git
```

## 交互式操作

运行脚本后，它会：

1. 列出所有可用的本地分支
2. 询问你要推送的本地分支（默认为当前分支）
3. 显示默认的远程分支名（本地分支名加上前缀`feat-beanquery-cnb/`）
4. 询问是否使用此默认远程分支名
5. 如果选择不使用默认远程分支名，则询问你要推送到的远程分支名
6. 执行推送操作

## 注意事项

- 确保已在GitHub和/或Gitee上创建了空仓库，并且有正确的访问权限
- 如果远程仓库URL与之前设置的不同，脚本会询问是否更新
- 脚本会自动处理不同名分支的推送

## 错误处理

脚本包含完善的错误处理机制：

- 参数不足时会显示使用说明
- 推送失败时会显示详细的错误信息和可能的原因
- 分支不存在时会提示错误并退出
