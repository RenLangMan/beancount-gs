# 变更日志

本文档记录 Beancount-GS 项目的所有重要变更。

## [未发布]

### 新增
- 创建了 `docs` 文档目录，包含使用说明、技术文档和变更日志
- 完善了项目文档结构，便于用户理解和开发者参与
- 集成了 beanquery 高级查询功能，支持类SQL语法查询财务数据
- 添加了 beanquery 命令行和Fava界面查询支持

### 修复
- 无

### 变更
- 更新了CNB环境配置，使用自定义Dockerfile（Dockerfile-python-go）创建同时包含Go和Python环境的容器
- 简化了开发流程，在同一环境中构建Go程序并运行Python应用
- 优化了查询性能，支持更复杂的财务数据分析

## [2023.11] - 2023-11-XX

### 新增
- 无

### 修复
- 将 `.cnb.yml` 文件中的 `source` 命令替换为 `.` 命令，提高了在标准 POSIX shell 环境中的兼容性
- 在 main 分支和 dev 分支配置中都进行了相应修改
- 保留了 `start_dev.sh` 脚本中的 `source` 命令，因为它是专为 Git Bash 环境设计的

### 变更
- 无

### 移除
- 无

## [2023.10] - 2023-10-XX

- 修复了多个依赖版本冲突问题

### 变更

- 更新了 Fava 依赖到 v1.30.5
